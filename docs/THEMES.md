## 设计共识（7 套共用）
- 只用 section / p / span / table / tr / td / br；样式全内联；文字全部 `<span leaf="">` 包裹；无 div / class / id / position / float / flex / grid / CSS 变量 / 外部字体 / 渐变。
- 正文 15px，行高 1.85，字距 0.5px，两端对齐；内容区左右 16px。
- 视觉三层：锚点（主色加粗，全文 ≤5 处）→ 标记（关键词下划线/荧光，每段 0–1 处）→ 容器（卡片、引用块）。
- 孤字保护：每段末 2 字＋标点不折行；大标题和判断句在第一个逗号处断行（或用 `@tbr` 指定断行位置）。
- ④–⑦ 继承 ① 的组件实现：没有单独覆写的组件会自动按本主题色板换色，所以 ① 的所有组件在 7 套里都能用。

## ① 喵叔蓝 · 科普卡片（miaolan）〔推荐日常主力〕
- 定位：日常条款释义、避坑、医保选择、家庭场景。与公众号封面、长图模板同一套品牌色，读者一眼认得。
- 示例文章：《同部位复发，第二笔重疾为什么一分不给》（20261030）。
- 色板：海军蓝 #051A4C（标题/深卡）、IP 蓝 #0288D1（锚点、章节号、数据高亮）、金 #F2A900（只在「人话」「避坑」「判断线」标签和头图短线）；灰阶承重 #3A4556 正文 / #55606F 次文 / #8A94A3 注释 / #E3EAF2 线 / #EEF7FD 浅底。
- 字体：系统黑体栈（PingFang SC / 微软雅黑）；头图标题 22px，章节标题 19px，正文 15px，卡内 14px，注释 12px。
- 组件：海军蓝标题区（喵叔说保徽标＋防坑｜买对｜赔好）、客户来问卡、导语卡、蓝色章节号＋标题、条款原文卡（原文＋人话）、判据框、举例卡、名词卡、深蓝金句、对比表（差异项蓝底白字）、横向数据条、避坑提醒（金边）、算一笔账＋双数据卡、双栏责任对照、编号门槛/清单、深蓝判断线、结尾关注引导、免责。

## ⑦ 测评擂台 · 产品横评（leitai）
- 定位：多款产品横评、两款同口径 PK、单品逐项拆解。与②暖纸编辑的区别：②是杂志读物感，⑦是对阵感、信息更硬。不打主观分、不排先后，条上的数字和✓都来自原文。
- 示例文章：《保费差不到100块的重疾险，赔的钱能差一半》（五款成人重疾，20261022）。
- 色板：白底、擂台黑 #15181E（头图、表头、回合标签）、红方 #E5483B / 蓝方 #2563C9（成对出现：红蓝对半线、对阵表两侧、单品卡交替）；灰阶 #2C2F36 / #5E636B / #959AA2 / 线 #E4E6EA、浅灰 #F4F5F7、红/蓝浅底 #FDEEEC / #EAF0FB。
- 字体：数字 DIN 栈；VS 斜体。
- 组件：擂台黑头图（红蓝对半线＋「同口径」说明行，来自 @basis）、ROUND 回合章节（红蓝方块交替＋红蓝对半线）、选手卡 roster（编号＋名字＋承保方）、红蓝对阵表 vs（左红右蓝中维度，更宽松一方加粗✓并铺浅底）、单品打分卡 card（不打分，逐项列原文写到的「多给的东西」）、分项条（== 指定焦点）、黑表头横评表（差异红字，写了✓才表示更宽松）、对半线划重点、犯规提醒（常见错写）、擂台结论、对半线金句。
