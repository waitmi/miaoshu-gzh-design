大家好，我是喵叔。

::: case 签字那天没人念的两行小字 | 主诉
几乎每周都有人拿着保单来问同一句话，保证续保20年，是不是这辈子不用愁了。把条款翻到中间，通常能看到两处小字。一处写着费率可调，一处写着保证续保期间届满后需经本公司审核同意。签字那天，这两句没人念过。

这两句话不是坑，条款本来就这么写。问题是签字那天，多数人只记住了「保证续保20年」这6个字，++没往下看它到底保证了什么++。

:::

## 定义逐段核对

::: basis 检验依据 | 《健康保险管理办法》第四条
《健康保险管理办法》第四条给过一个定义：保证续保条款，是指在前一保险期间届满前，投保人提出续保申请，保险公司必须按照原条款和约定费率继续承保的合同约定。

:::

这句话不长，但每一段都有边界。

::: report 定义四段 · 逐项检查结果 | 按上文定义逐段整理
| 前一保险期间届满前 | 时间窗口 | 第21年不在射程里 | warn |
| 投保人提出续保申请 | 要自己提 | 忘了申请就是没续上 | warn |
| 原条款 | 责任不改 | 既是好事，也是代价 | warn |
| 约定费率 | 可能可调 | 合同须写清条件、方式和上限 | bad |
| 理赔过、身体变差 | 不被单独拒保 | 也不能只给你一个人加价 | ok |
:::

「前一保险期间届满前」，说的是时间窗口。20年就是20年，第21年不在这句话的射程里。

「投保人提出续保申请」，说的是动作。续保要你自己提，不是自动扣款自动生效，忘了申请就是没续上。

「原条款」，说的是责任一个字都不改。这既是好事，也是代价，后面细讲。

「约定费率」这4个字最容易读错。很多人以为约定费率就是当初那张费率表，一辈子不动。银保监会在2022年专门答过一个提问，说这里的约定费率有两种情况，一种是原费率，一种是约定可调费率；费率可调的保证续保产品，必须在合同里明确告知费率可调，并写清调整的条件、方式和上限。

所以「保证续保」这4个字，**保的是「不被单独踢出去」这一件事**。你理赔过、身体变差了、查出新毛病了，它不能因此把你一个人挡在门外，也不能只给你一个人加价。对一个已经生过病的人来说，这句话有分量，它意味着往后这些年，这张保单不会因为你身体变差就消失。

这套东西是怎么来的，值得交代一句。2019年新版《健康保险管理办法》落地，把含保证续保条款的产品正式归进长期健康保险；第二年，监管部门又专门发了一份长期医疗险费率调整的通知，等于给「保证续保」开了一个费率可调的口子。逻辑很清楚：要让保险公司敢承诺20年，就得允许它在这20年里按规则调价，否则没人敢卖。所以++费率可调和保证续保是同一个制度里长出来的两件事++，拆开看反而容易看歪。

::: key
但它没保的事，还有三件。

:::

## 没保的事：价钱

先说价钱。

费率可调不等于想涨就涨。2020年那份关于长期医疗保险产品费率调整的通知，把程序写得很细：首次调整不能早于产品上市满3年，两次调整之间至少隔1年，每次调整要提前公示，公示满30天才能执行，而且不能因为某个被保险人身体不好就单独给他加价。还有一条硬杠，上一年度这个产品赔付率低于85%，并且比行业平均低10个百分点以上，当年不许上浮费率。单次涨幅也有上限，市面上的产品常见写法是不超过调整前费率的30%。

::: report 费率调整的程序门槛 | 按上文2020年长期医疗险费率调整通知的要求整理；单次上限为市面常见写法
| 首次调整 | 上市满3年后 | 不能早于这个时间 | ok |
| 两次调整间隔 | 至少1年 | — | ok |
| 公示 | 满30天才执行 | 每次调整提前公示 | ok |
| 单独加价 | 不允许 | 不因个人身体单独加价 | ok |
| 赔付率偏低 | 当年不许上浮 | 低于85%且低于行业平均10个百分点以上 | ok |
| 单次涨幅 | 常见不超30% | 程序合规，不等于价格不动 | bad |
:::

这套程序是消费者手里能拿来对账的东西。销售说费率可调，你可以顺着问三句：这个产品哪天上市的，上次调价是什么时候，公司网站上有没有挂公示。按规定这些信息都要放在公开信息披露专栏的长期医疗保险子栏目里，问得出来。

++但程序合规，不等于价格不动++。真到了赔付压力撑不住的时候，该涨还是会涨。

::: calc 按条款上限乘一遍
单次上限30%是什么量级，可以自己乘一遍。1.3乘4次是2.86，意思是如果按上限连调4次，保费就接近当初的3倍。这个乘法的前提是把条款上限用满，现实中很少这么走，但它是条款允许的空间。一个30岁的人买进去，20年里要跨过40岁、50岁这两个保费自然上涨的年龄段，再叠加可能的费率调整，那笔钱跟投保时算的完全不是一回事。

= 单次上限30%，连调4次
| 单次上限 | 30% | 条款允许的空间
| 连调4次 | 2.86倍 | 接近当初的3倍
:::

## 没保的事：责任

再说责任。

20年不许改条款，这一条反过来会咬人。产品卖出去就锁死，卖的时候没法试错，那设计的时候只能保守。保守的结果，是免责清单更长。

::: chips 翻几款保证续保产品的责任免除 | 按上文列举；各家写法差别很大，具体以条款为准
| 腺样体肥大 |
| 痔疮 |
| 腰椎间盘突出 |
| 颈椎病 |
| 鼻中隔偏曲 |
| 静脉曲张 |
| 睡眠呼吸障碍 |
:::

翻几款保证续保产品的责任免除，能看到一些在一年期产品里不太常见的名字：腺样体肥大、痔疮、腰椎间盘突出、颈椎病、鼻中隔偏曲、静脉曲张、睡眠呼吸障碍。这些不是罕见病，是门诊里天天见的。各家写法差别很大，具体要看条款，但方向一致，++锁得越久，口子收得越紧++。

这个规律也能解释另一件事：保证续保的期限有6年、20年、不设年限几档，期限越长，条款设计时越不敢松手。6年的产品三年后还能修一次，20年的产品卖出去就是20年，中间政策变了、药变了、就医方式变了，它都动不了。所以挑产品时看到「保证续保20年」这行字，先动的念头该是去翻责任免除和特药清单，而不是把它当成优点记下来。

::: report 条款停在原地，药在往前走 | 按上文引用的国家药监局2025年度药品审评报告整理
| 2025年批准1类创新药 | 76个 | 一年76个新药 | warn |
| 其中抗肿瘤药 | 34个 | 将近45% | warn |
| 你的特药清单 | 签字那年 | 停在签字那年的那一份 | bad |
:::

一边是条款停在原地，一边是药在往前走。国家药监局2025年度药品审评报告的数字是，2025年批准1类创新药76个，其中抗肿瘤药34个，占了将近45%。一年76个新药，而你的特药清单是签字那年的那一份。

这里要说句公道话，不然容易冤枉人。市面上确实有产品把院外药械不限清单写进了20年保证续保的主险条款，特药清单做到276种、含5种CAR-T，这类产品的责任是在跟着走的。所以不能笼统说保证续保就一定落后，得看具体产品把哪些责任放进了保证续保的范围。

## 没保的事：到期再申请

真正要盯的是第三件事，也是最少人提的一件。

::: lead
20年到期那天，还要再申请一次。

:::

条款里常见的写法是，保证续保期间届满前要重新提出续保申请，经公司同意承保并收到保费后进入下一个保证续保期间；届满时如果被保险人年龄超过80周岁，或者产品已经停售，公司不再接受续保申请。

45岁买进去，65岁到期。65岁重新做健康告知能不能过，是另一回事。而这20年里理赔过的人，恰恰是最需要保障、也最难重新投保的那批人。++保证续保把这道门推后了20年，没有把门拆掉++。

::: warn 一张保单，两种续保条款
这里还有一层更隐蔽的，很多人压根没意识到：一张保单里可能同时存在两种续保条款。

主险保证续保20年，特药、外购药械这些责任做成1年期附加险，不保证续保。附加险到期能不能续、责任怎么调，跟主险不是一套规则。销售说这张保单保证20年，说的是主险。你以为整张保单都锁了20年，其实锁的只是其中一部分，而最容易过时的那部分，恰恰常被放在不保证的那一边。

:::

::: report 把保单拆开看 | 按上文整理；以各产品条款为准
| 主险责任 | 保证续保20年 | 锁的是其中一部分 | ok |
| 特药、外购药械 | 1年期附加险 | 不保证续保，规则另算 | bad |
:::

所以买之前要做的一件事，是把保单拆开看：哪几条责任在主险里，哪几条在附加险里，各自的续保条款怎么写。++这一条比续保年限本身更要紧++。

## 池子里的机制

再往深一层，是个绕不开的机制。

::: term 死亡螺旋
保证续保的产品，健康的人容易走，因为新产品责任更全、价格更便宜；身体出过状况的人走不了，只能留下。人一年一年筛，池子里的赔付压力往上涨，压力涨到一定程度只能统一调费，调费又逼走一批还健康的人。这个循环行业里叫死亡螺旋。

:::

它跟哪家公司厚不厚道没关系，是产品结构决定的。所以判断一个产品能不能长期续下去，合同里那4个字说明不了太多，要看这个池子有没有新人进来、赔付率稳不稳、公司是不是把医疗险当主业在做。++合同承诺的是你有权续，经营状况决定的是你续得起、那个产品那时候还在++。

10月27日有个新消息，人保寿险上了一款长期医疗产品，125种重疾的保证续保不限年限，非重疾的住院医疗给20年保证续保，另外配短期加油包。

这个结构值得琢磨。连保险公司自己，也不愿意给一般住院开不限年限的口子，长期确定性只往重疾上收。原因不难猜，一般住院的费用受医疗通胀、医保政策、就医习惯影响太大，几十年的账算不准；重疾的病种和发生率相对稳定，才敢把期限放到不设年限。这也从侧面说明，保证续保能承诺多长，取决于这类风险有多好算，跟公司想不想对客户好关系不大。

## 一年期这一边的账

反过来说，一年期这一边的账，也该算清楚。

一年期产品每年都能改。今年条款设计有漏洞，明年就修；新药上市了，下一版就把它加进清单；医保政策变了，后年就能跟上。2025年一年批了76款创新药，能跟上这个速度的，靠的就是每年可迭代这个机制。一份20年动不了的合同，追不上一年76个新药。

续保这件事，实务里也没那么吓人。一年期产品续保通常不用重新做健康告知，公司发个续保通知，手机上确认就行。做了近10年，喵叔手上理赔过的客户，第二年该续的都续上了。这话讲的是实绩。合同里没这一条，靠的是那家公司一直把医疗险当主业做，一年一年维护下来。

挑一年期产品，就看三件事：这个产品卖了几年、迭代过多少版、公司的医疗险盘子有多大。一款产品能从2016年卖到今天、迭代二十几个版本，说明它一直在被维护，条款才有机会跟着药走。反过来，一个刚上线两年、公司主业务在别处的产品，就算业务员说得再好听，也值得多想一层。

::: report 挑一年期产品，复查三项 | 按上文整理
| 卖了几年 | 看年头 | 能卖到今天，说明一直在被维护 | warn |
| 迭代过多少版 | 看版本 | 条款才有机会跟着药走 | warn |
| 医疗险盘子 | 是不是主业 | 主业务在别处要多想一层 | warn |
:::

一年期也有它自己的代价，这点不遮掩。合同一年一签，产品停售了就没了，责任和费率每年都可能调整。所以「这家公司会不会一直做下去」是个真问题，得当成问题去问，别当成客套话去听。

还有一层容易被混着说：++保证续保保证的是「续保这件事」，不是「赔得到」++。条款管的是让不让你进门，理赔管的是进门之后赔不赔、赔多少。一份续得上但责任边界很窄的保单，续到第20年，该赔不到的还是赔不到。

## 体检结论

所以这篇的判断，喵叔给得直白一点。

::: rx 诊断意见
| 身体没大毛病、体检报告干净 | 一年期放在前面看 |
| 身体已经出过状况 | 保证续保有实打实的价值 |
| 预算宽裕、两头都想要 | 把保单拆开分别评估 |
绝大多数人，把一年期放在前面看。身体没大毛病、体检报告干净、还在能挑产品的年纪，最该在意的是这张保单能不能跟上药、跟上治疗方式。责任跟得上才叫保障，责任跟不上，续到第20年也一样赔不到你想赔的那笔钱。

保证续保留给一类人：身体已经出过状况、体检报告上有东西、去别家投保大概率被除外或者拒保的。对这批人，期间内不被拒保是实打实的价值，别的都可以往后放，价格和保额都排在它后面。

预算宽裕、两头都想要的，做法是把保单拆开：主险看续保，附加险看责任，分别评估。但要清楚，主险那20年锁住的是续保资格，锁不住责任水平。

:::

条款里那两行小字，买的时候都在，只是没人念给你听。念一遍，比听10句「保证续保」管用。
