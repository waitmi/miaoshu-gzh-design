大家好，我是喵叔。

## 先看你那儿有没有分档

2027年度的居民医保开始缴了，每年这个时候都有人卡在同一个问题上，一档还是二档。

先说一件很多人不知道的事，居民医保分档不是全国都有的。福建、湖南、河南、贵州、江西这些地方，从头到尾就一个标准，个人缴费就是国家定的下限400元，没有高低档可选。真正设两档的是少数地方，重庆、天津、山东部分地市、浙江部分地市才有。

::: key
所以你在别处刷到「一档二档怎么选」，头一步不是听建议，是++先确认你那儿到底有没有这个选项++。打12393问一句，或者打开缴费页面看有没有「一档」「二档」。

:::

## 431和806怎么拼出来的

有得选的地方，这道题怎么算。拿重庆2027年度的431和806做例子，算法你换成自己城市的数就能用。

先说431和806怎么拼出来的，今年这一栏是新加的。

一档是居民医保400元加长期护理保险31元，二档是775元加31元。财政补724元，长护险再单独补31元。长护险一年筹资62元，财政和个人各一半，你手上只掏31元。2027年1月1日前未满18周岁的孩子，跟着父母参保，这31元不用交。

::: table 重庆2027年度居民个人缴费 | 单位：元。按上文整理，未满18周岁的孩子不交长护险这31元
| 项目 | 一档 | 二档 |
| 居民医保 | 400 | 775 |
| 长期护理保险 | 31 | 31 |
| 个人合计 | 431 | ==806== |
| 财政补助 | 724 | 724 |
:::

重庆一档400元这个数，已经连续三年没动，跟全国下限标准一致，真正涨的是财政补助，今年到724元。所以账单上多出来的那部分，主要不是医保涨价，是长护险这一栏头一回向居民打开，以前只有职工医保参保人交。

::: warn 缴费截止日别按最晚的算
缴费时间上有个细节。市级文件写的是2026年10月到2027年1月，但很多区县的公告把截止日定在2026年12月31日，别按最晚的算。1月才缴的，待遇要从缴费次月才开始算，等于白白少保一个月。

:::

## 375元，差在三处

现在进正题，这375元买的是什么。++差在三处，住院的报销比例、住院的年度限额、门诊的年度限额++。

住院是大头。政策范围内费用扣掉起付线以后，一档在一级、二级、三级医院分别报80%、70%、50%，二档每个等级加5个百分点，85%、75%、55%，未成年人在这个基础上再各加5个百分点。起付线两档一样，一级100元、二级300元、三级800元。住院年度限额，一档8万，二档12万。

::: table 住院报销比例（政策范围内，扣起付线后） | 按上文重庆2027年度口径整理；未成年人各再加5个百分点
| 医院等级 | 起付线 | 一档 | 二档 |
| 一级 | 100元 | 80% | ==85%== |
| 二级 | 300元 | 70% | ==75%== |
| 三级 | 800元 | 50% | ==55%== |
| 住院年度限额 | — | 8万 | ==12万== |
:::

门诊只在二级及以下定点机构报，一级及以下不设起付线报60%，二级起付200元报40%，年度限额一档300元、二档500元。

门诊特病有53个病种，分两类。一类14种按住院的比例报，所以二档同样多5个百分点，封顶线跟住院合并。二类39种不设门槛，一年限额1000元，同时患两种以上的每多一种加200元，这一类两档完全一样。

大病保险这一层两档待遇一模一样，起付线2026年起是19856元，超过的部分报60%，一年最多报20万。参加居民医保就自动参加大病保险，不用另外掏钱。

## 一个公式算清楚

数据摆完了，开始算。这里给一个公式，你换成自己城市的数就能用。

::: formula 两档分界线怎么算
| 公式 | 档差 ÷ 比例差 ＋ 起付线 |
| 重庆代入 | 375 ÷ 5% ＋ 800 |
| 结果 | 约8300元 |
按上文原文公式整理；换成你自己城市的数就能用。
:::

::: calc 黑板推演 · 重庆
回本线，等于两档的差额，除以两档的报销比例差，再加上起付线。

重庆的数代进去，档差375元，比例差5个百分点，375除以5%是7500，加三级医院起付线800，**8300元左右**。取个整数，一次住院政策范围内花到8000元，二档多报的钱就够这375元。

= 一次住院，二档比一档多报
| 三级医院 · 政策范围内3万 | 1460元 | 一档14600 · 二档16060
| 二级医院 · 政策范围内1.5万 | 735元 | 一档10290 · 二档11025
:::

举个例子。三级医院住院，政策范围内3万元。一档报（30000减800）乘50%，14600元；二档报（30000减800）乘55%，16060元。差1460元，多交375，这一趟净赚1000出头。

再看二级医院，政策范围内1.5万。一档报（15000减300）乘70%，10290元；二档乘75%，11025元，差735元。也够本。

这一年要是住了两次，账就翻倍。==5%是按每次住院分别算的，不看累计==，没商保的话，住一次赚一次。

那要是这一年只在社区看感冒呢。门诊限额差200元，比例两档一样，二档最多多报200元，多交375，净亏175元。

::: verdict
判断线就出来了，一年里只要有一次8000元上下的住院，二档就回本；住两次就赚一倍；一次都没住，这375元就是净支出。

:::

## 各地差别有多大

这个公式真正有用的地方，是让你看清各地的差别有多大。

::: table 三地代入同一个公式 | 按上文整理；比例差为原文假设口径
| 地方 | 档差 | 比例差 | 分界线 |
| 重庆 | 375元 | 5个点 | 约8300元 |
| 天津 | 680元 | 按10个点 | 6800元 |
| 烟台 | 120元 | 按5个点 | ==2400元== |
:::

天津2027年度低档450元、高档1130元，档差680元。比例差如果按10个百分点算，回本线6800元，比重庆还低。档差大、比例差也大，两档拉得更开。

烟台2027年度成年居民一档400元、二档520元，档差只有120元。同样按5个百分点算，回本线2400元，随便住一次院就回来了。这种档差小的地方，二档基本不用犹豫。

反过来，要是哪个地方档差上千元、比例差只有3个百分点，回本线就要3万多，一年不住院就是纯支出。

所以别看别人怎么选。++先把你自己的两个数找出来++，档差多少，比例差几个点，公式一算，答案自己就出来了。

这话不好听，但医保本来就是这个逻辑。有篇讲医保的文章打了个比方，喵叔觉得挺准，医保像消费补贴，你得先产生消费，它才有用。一年不生病，交一档和交二档，在报销上没有任何区别。

## 两个容易被带偏的地方

再说两个容易被带偏的地方。

::: gates
头一个是封顶线。8万和12万看着差4万，很多人拿这个当选二档的理由。算一下就知道了，一档撞8万封顶，三级医院政策范围内得花到16万左右，二档撞12万要21.8万。这个量级的住院，自付早就超过19856元的大病起付线，大病保险已经在往里报，而大病保险两档完全一样。所以这4万，绝大多数人一辈子碰不到；碰得到的时候，真正接住你的是大病保险，不是那4万。

第二个是报销比例的口径。50%、55%这些数，是按政策范围内费用算的，不是按你结账的总金额算。起付线要先扣，目录外的药和耗材一分不报，目录内还有个人先行自付的部分，一层层扣完，剩下的才是那个比例。全国口径下，居民医保目录内住院的支付比例大约66%，职工大约84%，差18个百分点。这个66%已经含了大病保险，比单看三级医院50%高，但跟「花多少报多少」完全是两回事。

:::

::: key
所以那375元买到的，不是总费用多报5%，++是政策范围内费用多报5%++。这一点想明白，就不会对二档有不切实际的期待。

:::

## 有商保的，选哪档

还有个问题每年都有人问，有商业保险的，是不是选一档就行。

方向是对的，但理由得说清楚，不然容易被理解成有商保就可以少交医保。

::: term 报销型医疗险
报销型医疗险赔的是什么。医保报完，你自己掏的那部分，扣掉免赔额，剩下的它才赔。所以医保多报5%，商保就少赔5%，你最后到手的钱一分没多。多交的这375元，等于把商保本来该赔的那部分，挪回医保来出。==钱从左手换到右手，总额没变==。

:::

但得先过免赔额。百万医疗多数是年累计1万，中高端有的0免赔，惠民保这类产品的线还要更高。一年里自付累计没到免赔额的，商保一分不赔，这时候二档多报的5%是实打实进自己口袋的。过了免赔额，商保接手，两档最后自己掏的钱都会收敛到那个免赔额上，二档多交的375就白交了。

没商保的人不是这样。二档多报的5%跟着住院费一起涨，没有上限，住一次10万的院，二档多报5000。有商保的人拿不到这一块，多出来的被商保抵掉了。

所以商保对选档的影响，是把二档的收益封了顶。有商保的人选二档，最多多拿900元上下，出现在住院费1.9万左右；过了2.1万，两档到手一样，375白交；不到8000，连本都不够。

::: warn 这里的不对称
这里的不对称要看清。二档想多拿钱，得住院费落在8000到2.1万、一年只住这一次、自付没破免赔额，三个条件同时成立。一档省下的375元，不需要任何条件。一年住两次以上的更该选一档，免赔额是年累计的，第二次住院时自付早就过线，二档全年的5%都被商保抵掉。

:::

所以手里有报销型商保的人，**选一档更稳**。不是二档一定亏，是二档赚的那几百块要靠条件凑齐，亏的那375不需要。

三个边界说清楚。0免赔的中高端医疗，二档的5%几乎全被抵扣，一档更明确。只买了重疾险、住院津贴这类给付型，没有报销型医疗险，医保多报的钱是净增量，那就回到前面那条公式。最后一条最重要，有商保不等于可以不交医保，多数百万医疗是按有社保的费率投保的，理赔时没用医保结算，赔付要打6折。选一档也是医保，该刷的卡照样刷，这条不受影响。

## 账单上那31元：长护险

接下来说长护险，就是重庆账单上那31元。

这一栏不是重庆自己加的，是国家在推。2026年3月，中办国办发布了《关于加快建立长期护理保险制度的意见》，要求用3年左右时间基本建起来，到2028年底全国基本实现全覆盖。这是社保的第六险。

费率全国统一控制在0.3%左右。在职职工单位和个人各一半，退休人员0.15%，没有工作的城乡居民从0.15%左右起步，用5年左右过渡到0.3%，个人和财政合理分担。报销比例，职工大约70%，居民大约50%，不设起付线，年度支付上限不超过当地上年度居民人均可支配收入的50%。

::: table 长护险，职工和居民不一样 | 按上文整理；各地进度不一，以当地文件为准
| 项目 | 职工 | 居民 |
| 费率 | 0.3%左右 | 0.15%左右起步 |
| 报销比例 | 约70% | 约50% |
| 起步保障 | 含中度失能 | ==只保重度== |
:::

各地进度不一样。重庆是2027年度起把居民纳进来，个人31元；吉林2027年度个人25元，跟居民医保一起收；烟台只有龙口、长岛等几个区市在试点，其他区市还没开展。

钱怎么用，有几个硬条件。

::: term 长护险管什么
它不管看病，管的是失能以后的照护，洗澡、喂饭、翻身、换药、失禁护理这些事。2027年1月1日起，重庆的居民参保缴费以后就可以申请失能等级评估，结论有效期24个月，从受理到出结论最长30个工作日。

:::

门槛不低。起步阶段只保重度失能，职工那边含中度，居民这边不含，而且要失能状态持续6个月以上，经规范诊疗或者康复之后仍然如此。

待遇是三种形式，居家护理、社区护理、机构护理，自己选。服务项目从原来的28项扩到36项，加了吸痰、换药、鼻饲、吞咽训练这类医疗护理。

::: warn 不发现金
有一条要特别注意，**它不发现金**。基金按定点机构实际提供的合规服务结算，钱不进你口袋。指望交几十块领补贴的，方向就错了。

:::

::: warn 等待期比医保长
还有个坑，长护险的等待期比医保长。重庆这边，医保断保再参保是固定等3个月，每多断1年加1个月；长护险从2027年起是固定等6个月，同样每多断1年加1个月。

:::

最后提醒一句，这个钱不是一直这个价。居民费率现在按0.15%起步，5年过渡到0.3%，等于翻一倍。重庆这31元，过渡完大概率是62元，其他城市同理。

几十块买的不是钱，是一条通道。真到了「一人失能、全家失衡」那天，有个专业护理体系能接得住，这钱就值。++但它是兜底，不是保障++，别指望它能覆盖请护工的钱。全国60岁以上老人3.2亿，失能老人约3500万，这个数字摆在这，制度早晚要建，早参保早攒年限。

## 每年都有人踩的点

最后说几个每年都有人踩的点。

::: steps
满60岁照样要交。居民医保交一年保一年，没有「到龄免缴」这回事，70岁、80岁只要没有职工退休医保，一样按年缴，只有特困、低保这类资助对象才免。

档次一年只能改一次。多数地方把变更窗口放在集中缴费期，一旦进了保障年度，中途想从低档升高档基本办不到。还有的地方系统会默认沿用你上一年的档次，你手动填了低档金额，没去医保渠道做变更登记，最后还是按原档次入账。++缴费前花两分钟确认一下++，比事后跑退费省事。

别断保。除了新生儿和救助对象，没在集中期参保或者断保的，都要设待遇等待期。从2025年起还有个正向激励，连续参加居民医保满4年以后，每多连续1年，大病保险限额加4000元；当年一次没报销、第二年正常参保的，也加4000元。断保断掉的不只是几个月待遇，还有这个额度。

别重复参保。已经在交职工医保的，不要再缴居民医保，重复参保只保留一个关系，钱不退。想用职工个人账户给配偶、父母、子女代缴的，要先去医保部门办个账关联，不然扣不了款。

:::

## 到底怎么选

那到底怎么选。

::: table 对号入座 | 按上文结论整理
| 你的情况 | 选档 |
| 手里已经有百万医疗险 | ==一档== |
| 只买了惠民保这类高免赔产品 | 二档还有用 |
| 家里有老人、学龄前孩子或门特病人，又没有报销型商保 | 二档 |
| 20几岁、身体干净、没商保 | 一档够用 |
| 30到40岁的中间人群 | 看预算 |
:::

手里已经有百万医疗险的，一档。省下的钱当场落袋，二档想多拿那几百块，得凑齐三个条件，不划算。

只买了惠民保这类高免赔产品的，二档还有用。这类产品免赔额比百万医疗高，一年自付到不了那条线的概率更大，二档多报的几个点更容易落进自己口袋。

家里有60岁以上的老人、有学龄前的孩子、有人办了门诊特病需要长期治疗的，又没有报销型商保，二档。这三类人住院的概率摆在那，公式算出来的回本线基本一次就过。

20几岁、身体干净、没商保、一年进不了几次医院、单位也没给交职工医保的，一档够用。省下的钱，够买一份百万医疗险的头一年保费，那层兜的是目录外的钱，比多几个百分点管用。

中间那部分人，比如30到40岁、家里老人身体还行、自己有小毛病但没住过院的，看预算。几百块不算多，买的是万一住了院不至于太心疼，这个心理账也算账。

::: quote
真正该纠结的从来不是那几百块，是这一年会不会住院。这道题没人算得准，只能按家里人的身体状况押一个方向。

:::

医保保的是底线，不是全部。多交的这笔钱决定的是这条底线厚一点还是薄一点，决定不了够不够。够不够这件事，得靠第二层。

::: end
