## 四份原文先摆出来

重疾多次赔这条责任，4款主流产品都写了「同种重疾可以再赔一次」。宣传页上就这一行字。但每一款后面都挂了一条排除项，叫持续状态不赔。++差别全部在「什么算持续状态」这句话里++。

::: clause 达尔文12号 | 复星联合健康承保 | 原文写
如果自首次或第二次重大疾病确诊后，再次确诊罹患与首次或第二次重大疾病相同且病灶部位完全一致的疾病，即视为重大疾病的持续状态。
?? 只看部位，不看治没治好
:::

::: clause 完美人生8号 | 也是复星联合健康，同公司另一个产品 | 原文写
自首次重大疾病确诊之日起满1095天后，再次确诊罹患与首次重大疾病相同且病灶部位完全一致的疾病，即视为重大疾病的持续状态。
?? 只看部位，不看治没治好
:::

::: clause 超级玛丽17号 | 海保人寿承保 | 原文大意是
自最近一次重大疾病确诊之日起满730天后，经医院专科医生再次确诊患有本合同所列的重大疾病，属于被保险人首次或第二次确诊的重大疾病经过治疗后并未完全好，且与被保险人首次或第二次确诊的重大疾病相比，疾病诊断及病灶部位完全一致。
?? 多一道前提，前一次得是治疗之后没有完全好
:::

::: clause 哪吒2号 | 也是海保人寿 | 前面那段与超级玛丽17号一致，后面多了一句
若被保险人首次或第二次确诊的重大疾病为恶性肿瘤重度，因首次或第二次病变部位恶性肿瘤导致的恶性肿瘤转移或扩散，到达继发组织或器官继续增殖生长并形成与原发恶性肿瘤有相同病理学及组织学类型的继发恶性肿瘤，属于重大疾病的持续状态。
?? 四款里只有它把转移写进持续状态
:::

::: key
四段话读下来，判据只有两个。病灶部位一不一致，要不要证明前一次没治好。
:::

## 要不要举证「没治好」

达尔文12号和完美人生8号++不看治没治好，只看部位++。同一个位置再查出来，直接算持续状态。

超级玛丽17号和哪吒2号多了一道前提，++前一次得是治疗之后没有完全好++。

::: example 同侧复发，两种口径
这道前提在实际理赔里是有分量的。乳腺癌手术切除，病理达到临床完全缓解，第4年同侧胸壁又长出病灶。这种情况在超级玛丽17号的口径下不落进持续状态，可以按新的一次重疾赔。在达尔文12号的口径下，部位一致，落进持续状态，这笔不赔。
:::

举证落在病历上。复查报告、影像、病理，能不能说明上一次没治透，决定这笔钱赔不赔。++条款把认定权交给了材料++。

::: term 复发 ≠ 持续存在
日常说癌症复发，指的是又长出来了，不问治没治好。条款里的复发有严格定义，得是经过手术或放疗达到临床完全缓解、病灶消失，过一段时间原部位又长出同病理类型的肿瘤。临床上还有一种情形叫持续存在，病灶从来没消失过，一直在治疗。这两种在条款里走两条路。日常一句话，条款里是两个案子。
:::

## 转移这一句只有一家写

四款里只有哪吒2号白纸黑字把转移写进持续状态。原发部位的癌细胞跑到别的器官，形成同样病理类型的继发肿瘤，算持续状态，不赔。

超级玛丽17号那段没有这句话。转移出去的继发肿瘤，部位已经与原来不一致，按「病灶部位完全一致」这个字面读，也落不进持续状态。

达尔文12号和完美人生8号同样只有「部位完全一致」这一句。转移到肝、到骨、到脑，部位对不上，字面上不落进。

这三家等于把「转移算不算」留在了空白处。

空白处没有答案。继发肿瘤与原发同病理类型，理赔时怎么认定是不是同一次病的延续，条款没写，三家都没写。所以网上那些「这款转移不赔、那款转移能赔」的说法，只有哪吒2号那一句有原文兜底，其余都是推论。

::: quote
推论可以看，不能当条款用。
:::

| 产品 | 看部位 | 须举证 | 写转移 |
| 达尔文12号 | 是 | 否 | 未写 |
| 完美人生8号 | 是 | 否 | 未写 |
| 超级玛丽17号 | 是 | ==是== | 未写 |

## 间隔期差整一年，而且分版本

同种重疾的间隔期，四款不一样，++同一款产品里还分版本++。

达尔文12号两个版本。65周岁版同种间隔1095天，保一辈子那一版730天。两个版本只能选一个，投保时不会有人专门提醒你这一条差了一年。

完美人生8号是1095天，限65周岁前首次确诊，而且只赔一次。65岁以后首次发病，这条责任自动失效，钱白加。

超级玛丽17号是730天，限65周岁前首次确诊，第二、三次各赔120%。

哪吒2号是730天，分70周岁前和保一辈子两个版本，两个版本的间隔都是730天。

::: bars 同种重疾间隔期 | 单位：天
达尔文12号 · 65周岁版 | 1095
达尔文12号 · 保一辈子版 | 730
完美人生8号 | 1095
超级玛丽17号 | 730
哪吒2号 · 两个版本 | 730
:::

730天和1095天差整一年。癌症复发的高峰就在确诊后2到3年这个窗口，多等一年，撞上的概率不一样。++这个数字比赔付比例实在++。

单次赔付比例四款都是120%，这一栏没有差别，看比例挑不出东西。差别在次数和年龄门槛。完美人生8号与达尔文12号65周岁版都只多给一次，超级玛丽17号和哪吒2号能到第二次、第三次。

::: warn 横评常见错写
网上不少横评把达尔文12号的同种间隔写成3年，把保一辈子那一版那2年抹掉了。也有写成2年，把65周岁版那3年抹掉的。两个版本并存，写一个就是不完整。
:::

## 为什么条款要这么写

有人看到排除项会觉得是坑。把定价逻辑摆出来，这事能看明白。

重疾险的保费，是按「一个人一辈子得几次重疾」这个概率算出来的。一次确诊赔一笔，这个假设撑得起几百块一年的价格。如果同一场病每复发一次就赔一次，等于把单次重疾变成无限次，价格会翻几倍上去，没人买得起。所以条款把「同一场病」按一次算，把「再得一种别的病」按另一次算，++这条线划在持续状态上，是定价算出来的++。

这也解释了为什么四款产品的写法能差这么多，却都在同一条排除项上。++排除项是共同的++，怎么界定持续状态是各家自己拿捏的松紧。

这条排除项也不只针对癌症。严重脑中风后遗症本身就是状态定义的病，得满足180天后仍遗留功能障碍才算确诊。这种病在条款里天生没有「复发」这回事，反复发生的是新的一次中风，不是同一个状态。所以那条排除项对非癌的重疾一样生效。癌症只是最常撞上它的一种。

## 这条责任本来就不管复发

四份原文读下来会发现一件事。这4款产品的重疾多次赔，全都把持续状态排除在外。差别只在「什么算持续状态」，没有一款说「持续状态也赔」。

所以同部位复发能不能拿第二笔，在这个责任里，++答案基本是否定的++。位置一致就落进去，位置不一致才出得来。

那复发靠什么赔。靠另一条责任，**恶性肿瘤医疗津贴**，条款全称常写成恶性肿瘤重度医疗津贴保险金。

这4款产品都另有一条。触发条件写的是「仍处于恶性肿瘤重度状态并进行治疗、随诊或复查」，++覆盖新发、复发、持续、转移四种状态++。癌到癌间隔365天，非癌到癌间隔180天。

::: calc 算一笔账
算一笔账。50万保额，同侧肺再查出病灶，落进持续状态。
只加重疾多次赔，第二笔是0。位置一致，排除项直接命中。
加了癌症津贴，满1年仍处于该状态，赔40%，20万。第2年还在治疗，赔50%，25万。第3年，赔30%，15万。累计60万。
= 50万保额 · 同侧肺再查出病灶
| 只加重疾多次赔 | 0 | 排除项直接命中
| 加了癌症津贴 | 60万 | 20万 + 25万 + 15万
:::

间隔期也差一截。津贴1年一结，重疾多次赔同种要等2到3年。

::: duo 两条责任管的是两件事
多次赔 | 管「再得一种别的重疾」，心梗之后又脑中风，癌症之后又心梗，这类跨病种的第二次，它有用。
津贴 | 管「同一种癌症在时间上的延续」，复发、转移、持续治疗都在里面。
:::

问题出在投保那天。多数人勾了重疾多次赔，以为「二次」这件事就解决了，津贴那一栏空着。++真到同部位复发，才发现勾的那条不管这个++。

## 津贴这一侧的三道门槛

津贴这一侧也有它的边界，三个前提，++缺一个就不触发++。

::: gates
头一个是首次重疾得是恶性肿瘤重度。首次如果是心梗，津贴走非癌到癌那条路，间隔180天，首笔40%，后面再按癌到癌接。路径不一样，钱也不一样。
第二个是得有「仍在治疗、随诊或复查」的记录。病灶切干净了，5年没复查，突然想起来申请，这一条过不去。津贴赔的是还在治的那段时间，不是赔一次历史确诊。
第三个是次数上限。3次，累计40%加50%加30%，等于120%。到顶就停。癌症拖到第4年还在治，这条不再给钱。
:::

::: warn 完美人生8号多一层
完美人生8号还多一层。它的恶性肿瘤医疗津贴与第二次恶性肿瘤重度保险金只能二选一，选了津贴，那条1095天的二次癌症责任就没有了。这两条金额和间隔都不一样，投保页面上是个勾选项，勾错了不会弹提示。
:::

四款的津贴比例也有出入。超级玛丽17号、达尔文12号、完美人生8号都是40%、50%、30%，哪吒2号是50%、40%、30%。网上有稿子把超级玛丽17号写成50%、40%、30%，官方产品页与条款表格是40%开头。++50万保额口径下，头一笔差5万++。

## 买前翻三页

::: steps
头一页，释义。找「持续状态」这4个字，看三件事。病灶部位怎么规定，要不要举证前一次没治好，转移写没写进去。这三件事决定同部位复发能不能赔，比「赔几次、赔多少」重要得多。
第二页，多次赔的版本。达尔文12号两个版本间隔差一年，完美人生8号只有1095天那一版，超级玛丽17号和哪吒2号是730天但限首次确诊年龄。版本与年龄门槛要一起看。
第三页，附加责任清单。找「恶性肿瘤医疗津贴」，看加没加。这一条是同部位复发独一份的入口。还要看它和别的责任有没有二选一。
:::

## 判断线

::: verdict
绝大多数人，**津贴先加，多次赔后加**。
:::

理由是津贴的触发条件更贴近真实病程。复发、转移、持续治疗都算，间隔1年，比例前高后低，钱来得早。多次赔要等2到3年，还得是「新的一次」，同部位复发基本被排除项挡住。++对癌症这条线，津贴的确定性更高++。

预算够的，两条都加。它们管的事不重叠，一条挡跨病种的第二次，一条挡同一种病的延续。

预算只够一条的，先津贴。这条判断不涉及哪款产品更好，++只涉及钱花在哪条责任上更可能用得上++。

已经买过的人，翻保单的附加责任那页，看有没有「恶性肿瘤医疗津贴」这一项。没有的话，保单没买错，是那一栏当时没人跟你讲清楚它管什么。

::: quote
条款里那4个字，买的时候都在，只是没人念给你听。念一遍，比听10句「同种重疾可赔」管用。
:::

::: end
