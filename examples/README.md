# 示例标记稿

前 5 篇是「喵叔说保」公众号已发布文章的标记稿；第 6 篇是喵叔长图模板（2026-10-30）的选购清单示例改写成的原文，产品均为虚构示例（原文段落一字未改，只加了结构标记），用来生成 `docs/previews/` 里的预览图。

| 标记稿 | 文章 | 用于主题 |
|---|---|---|
| `同部位复发.gzh.md` | 同部位复发，第二笔重疾为什么一分不给 | ① 喵叔蓝 · ② 暖纸编辑 · ③ 深蓝鎏金（同篇横向对比；8 套全流程验证也用这篇） |
| `孩子医疗险免赔.gzh.md` | 同样叫0免赔，有的一款全额赔有的一款只报80% | ④ IP蓝瑞士网格 |
| `保证续保.gzh.md` | 保证续保20年，保的只是不被单独踢出去 | ⑤ 保单体检报告单 |
| `居民医保一档二档.gzh.md` | 居民医保交一档还是二档，一次住院就能算清 | ⑥ 黑板荧光笔 |
| `五款重疾横评.gzh.md` | 保费差不到100块的重疾险，赔的钱能差一半 | ⑦ 测评擂台 |
| `重疾医疗选购清单.gzh.md` | 重疾险·医疗险选购清单（附原文 `.md` 与 `.spec`） | ⑧ 选购清单（8 套全流程验证、产品列表组件示例） |

```bash
python3 scripts/build.py tijian examples/保证续保.gzh.md          # 单套
python3 scripts/build.py all examples/同部位复发.gzh.md            # 8 套全出
```

python3 scripts/build.py all examples/重疾医疗选购清单.gzh.md --src examples/重疾医疗选购清单.md   # 带原文做覆盖比对
python3 scripts/compose.py examples/重疾医疗选购清单.spec    # 由原文重新拼出标记稿
